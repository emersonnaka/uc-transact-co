The seven fields

A Tasks Pack specifies exactly one objective. Three fields for the human, three for the machine, and one for the graph.

The seven fields of a Tasks Pack. Fields 1, 2, 3 are written by a human or reviewed by one. Fields 4, 5, 6 let the agent answer "am I done?" without asking. Field 7 lets a hundred packets order themselves.

Movement 02 · sizing rule

One objective.
No "and".

One objective, one area of the codebase, verifiable by the steps it contains, ends in one clean commit.

the split rule
If the title needs "and" to be honest, it is two packets.
The sizing rule: Ralph Loop's "one objective, split on the 'and'".
[Sources] plan/d3-agenda.md — The rule that makes a packet atomic [/Sources] Talk track: A plan is how humans agree. A packet is how an agent finishes. The window is finite, so the unit has to be small enough to close inside it. If you need 'and' in the intent sentence, you have two objectives, which means two packets. Split it.
