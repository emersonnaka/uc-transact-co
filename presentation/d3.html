What makes an eval terminal

Terminal just means the machine can answer it alone — yes or no, no human in the loop. If it can't, it's a draft.

01 · Deterministic
Same inputs, same answer
The answer doesn't change with who runs it or when.
Not terminal when it reads a live dashboard — the number moves while you look.
02 · Idempotent
Run it twice, same result
Running it changes nothing — not the answer, not the code.
Not terminal when it edits the file it's checking.
